# 项目记忆

这里保存经过筛选、可追溯的项目背景，帮助后续任务快速找到相关资料。最后核对日期为 2026-11-28。

- [项目状态](state.md)概述架构、前端入口和待核实事项。
- [维护决策](decisions/maintenance.md)记录现有工作约束及其来源。
- [来源与采用情况](sources-decisions.md)记录参考资料的处理方式。
- [记忆变更记录](changelog.md)记录本目录的主要变化。

AI 在仓库工作中按照 [AGENTS.md](../AGENTS.md) 的项目记忆规则，开始改动前阅读本入口和任务相关条目，并回到来源核实。代码、配置和用户当前要求可能发生变化。任务改变或确认值得长期保留的项目背景时，同步维护相关记忆并记录来源、核实日期及不确定性。避免保存凭据、个人隐私和未经验证的推测。源码级改动按照项目规则记录在[改动日志](../docs/upstream-sync-log.md)。
